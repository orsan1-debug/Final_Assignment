AUTHORS' REPLICATION PACKAGE
Angrist, J. D. and V. Lavy (1999), "Using Maimonides' Rule to Estimate
the Effect of Class Size on Scholastic Achievement", Quarterly Journal
of Economics 114(2), 533-575.
=========================================================================

This is the replication package the authors deposited with the journal.
It is NOT part of your task, and it is NOT something you are expected to
open.

WHY YOU HAVE IT
  It is public, so you would find it anyway. Posting it here just means
  nobody is at an advantage for having gone looking.

WHAT IT DOES NOT CHANGE
  The code you hand in must be written by your group. Slides and code
  are run through a similarity-detection system that compares them
  with, among other things, the authors' own code.

  In the Zoom code session you must be able to say what any line of
  your code does, why it is there, and why you did it that way rather
  than another. That is far harder with code you copied than with code
  you wrote.

  Your task list (what_to_replicate.txt) defines what your code must
  produce. Where this package and your task list differ, YOUR TASK LIST
  WINS: the authors produced exhibits you are not asked for, and your
  task list allows simplifications the authors did not take.

  DO NOT AIM TO REPRODUCE THE PAPER'S EXACT NUMBERS. That has not
  changed either. Having the authors' code does not turn their numbers
  into a target - see "How your code is judged" in PROJECT_README.txt.

WILL IT RUN?
  Almost certainly not as it stands. This code was written for the
  authors' own machine and their own folder layout, and it often reads
  files that are not in your package. Do not spend time trying to make
  it run.

WHAT IS IN THIS FOLDER
  AngristLavy_Table2.do ... AngristLavy_Table5.do
      One do-file per table, covering Tables II to V.
  mmoulton_post.do
      The authors' implementation of the Moulton standard-error
      correction, called by the table do-files.

  Note that there is no do-file here for Table VI, which is on your
  task list. That one you write from the paper.
