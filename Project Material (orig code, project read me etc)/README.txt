Angrist, J. D. and V. Lavy (1999), "Using Maimonides' Rule to
Estimate the Effect of Class Size on Scholastic Achievement",
Quarterly Journal of Economics 114(2), 533-575.

FOLDER CONTENTS
  paper.pdf                    The published article.
  what_to_replicate.txt        The exhibits your group must reproduce.
  data/final4.dta              Fourth-grade classes, one row per class.
  data/final5.dta              Fifth-grade classes, one row per class.
  data/data_dictionary.xlsx    Variable definitions, one sheet per
                               data file.

SOFTWARE
  Stata. No SSC packages are required.

DATA NOTES
  Variable definitions, units and codings are in
  data/data_dictionary.xlsx. Each row of a .dta file is one class.
  Classes in the same school share schlcode; classid numbers the
  classes within a school. The two .dta files cover different pupils
  (grade 4 and grade 5) and have the same variable layout; they are
  used separately, and can be appended where an exhibit pools the two
  grades.

SUBMISSION
  Submitted code must be your group's own work (Moodle policy).
